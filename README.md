# Snowflake + dbt Analytics Engineering

A public-safe analytics-engineering reference that demonstrates raw-to-staging-to-mart transformations, dimensional modeling, data-quality tests, and lineage concepts used in Snowflake/dbt environments.

## Demonstrates
- raw / staging / mart layers
- star-schema modeling
- incremental-style transformations
- dbt-style data-quality tests
- finance and revenue marts
- lineage and observability

The demo runs locally with synthetic data and does not require Snowflake credentials.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```
